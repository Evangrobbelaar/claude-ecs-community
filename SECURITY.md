# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.x | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in Claude ECS, please do NOT open a public issue.

Email: evangrobbelaar@gmail.com
Subject: [SECURITY] Claude ECS Vulnerability

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

You will receive a response within 48 hours.

## Important Security Notes for Users

1. **Never commit your GitHub PAT to any file** — store it in Claude memory only
2. **Keep your context file private** if it contains sensitive information
3. **Rotate your PAT regularly** — generate a new one every 90 days
4. **Your context repo can be private** — Claude can still read it with the PAT
