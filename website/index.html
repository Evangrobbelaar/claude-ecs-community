The Problem

Claude Reads Rules.
It Doesn't Follow Them.

Every Claude memory solution stores your rules as passive text. Claude reads them — sometimes. Under pressure, during fast analysis, when things get complex — it skips steps. That's how a R1,046 account nearly got wiped on one trade due to wrong lot sizing.

01

Internal memory fails

Claude's built-in memory stores rules as suggestions. Process steps get skipped when Claude is under pressure to respond quickly. This is not a Claude flaw — it is an architectural limitation.

02

Existing solutions require installation

claude-mem, claude-memory, supermemory — all require npm, Python, terminals, and background processes running on your machine. Built for developers, not retail traders.

03

Memory is not enforcement

Remembering a rule and being blocked from breaking it are completely different things. No existing system enforces — they only remind. Claude ECS blocks.

04

Context resets every conversation

Every new chat, Claude starts from zero. Months of learned behaviour, rules, and hard-won lessons disappear. You re-explain everything, every time.

FAQ

Common
Questions.

Does this work on the free Claude plan?
Yes. Claude ECS uses bash git commands and web_fetch — both available on any Claude plan including free. The GitHub account is also free.
Does it work with brokers other than ThinkMarkets?
The system was built and validated exclusively on ThinkMarkets using their ThinkTrader MCP integration. The rules and framework can be adapted for other brokers but ThinkMarkets is the only validated platform.
How is this different from claude-mem or claude-memory?
Those solutions require installation (npm/Python), only work in Claude Code, and only store memory passively. Claude ECS works in claude.ai chat, requires nothing to install, and actively enforces rules — blocking trades if any checklist item fails.
Is my trading data private?
Completely. Your context file lives in YOUR GitHub repository — private or public, your choice. No data is sent anywhere except between you and Claude. You have full sovereignty over your trading context.
Does Claude make autonomous trading decisions?
No. Claude analyses market structure, identifies setups, and executes trades — but only when you approve. The enforcer blocks bad trades automatically, but every final decision is yours. This is a discipline tool, not an automated bot.
What happens if Claude doesn't say "Context loaded"?
Simply say "Read your context file first" — Claude will immediately fetch the GitHub file and load all rules before doing anything else. The verification phrase is your guarantee the system is active.
Can I edit the context file myself?
Yes — open the file on GitHub and edit directly in your browser. Changes are live immediately for the next conversation. You have complete control and visibility over Claude's entire "brain."
What is the Claude ECS community?
An open source GitHub community where traders and developers share real lessons, proven rules, and validated setups. Contributions are voluntary and attribution is always given. The community makes the system better for everyone.
