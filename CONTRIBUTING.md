# Contributing to Claude ECS Community

Thank you for contributing to the Claude External Context System.
Every contribution makes the system better for everyone.

---

## What to contribute

### Lessons (community/lessons/)
Real lessons learned from real sessions. Format:

```markdown
## Lesson: [Short title]
Date discovered: [Month Year]
Use case: [Trading/Software Dev]
Contributor: [GitHub username or Anonymous]

### What happened:
[Describe the situation that led to this lesson]

### What went wrong or what worked:
[The specific outcome]

### The lesson:
[The rule or principle extracted — one clear sentence]

### How to prevent/replicate:
[Specific actionable guidance]
```

### Rules (community/rules/)
Proven rules that work across multiple sessions. Format:

```markdown
## Rule: [Short title]
Validated by: [Number] sessions
Use case: [Trading/Software Dev]
Contributor: [GitHub username or Anonymous]

### The rule:
[One clear sentence]

### Why it works:
[Brief explanation]

### Example:
[Real example of the rule in action]
```

### Templates (templates/)
Complete context file templates for specific use cases.
Must be tested for at least 5 sessions before submission.

---

## How to submit

1. Fork this repository
2. Create a branch: `git checkout -b contribution/your-description`
3. Add your content to the relevant folder
4. Commit: `git commit -m "Add [type]: [short description]"`
5. Push and open a pull request
6. Describe what you tested and what results you got

---

## Rules for contributions

- No personally identifiable information
- No account credentials, API keys, or tokens
- No unvalidated theoretical rules — real sessions only
- No results you can't verify
- Keep it anonymised — lessons, not personal stories

---

## Community guidelines

- Be honest about results — don't exaggerate
- Credit others when building on their work
- Keep discussions constructive
- Remember: this system was built from real mistakes
  Sharing failures is as valuable as sharing wins

---

## Recognition

Top contributors will be:
- Listed in the README Hall of Fame
- Credited in release notes
- Acknowledged in any commercial products built on their contributions
